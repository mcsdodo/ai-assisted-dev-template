# TODOs

Lightweight scratchpad for items not yet worth a full `_tasks/{NN}-{name}/` folder. Think "inbox" — jot things down here, promote them to a task folder when you're ready to plan them properly.

## Rules

- One item per line
- No dates, no owners, no status — if you need structure, it's a task
- Delete the line when the item is done or promoted
- If this file grows past ~20 items, triage it into real tasks
